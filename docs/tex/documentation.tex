\chapter{Introduzione}

\section{Obiettivo}

L'obiettivo del progetto è creare un hangar intelligente per un drone. Si divide il sistema in due sottosistemi:
\begin{itemize}
    \item \textbf{Drone Hangar (Arduino)}: Il sistema che gestisce l'apertura e chiusura dell'hangar, controlla la temperatura e segnala lo stato di allarme quando raggiunge una certa temperatura. L'Arduino manda delle informazioni sullo stato corrente dell'hangar all'applicazione Java tramite seriale.
    \item \textbf{Drone Remote Unit (PC)}: Il sistema Java che serve da interfaccia tra l'operatore e l'hangar. L'applicazione manda dei comandi tramite seriale all'hangar quando si vuole uscire dall'hangar o entrare nell'hangar in base a dove si trova il drone. Utilizza Swing come interfaccia grafica.
\end{itemize}

\section{Task implementate}

\begin{itemize}
	\item \textbf{AlarmTask}: Gestisce lo stato dell'allarme in base alla temperatura corrente. Quando l'hangar è in allarme si può resettare solo quando la temperatura è tornata normale.
	\item \textbf{BlinkingTask}: Gestisce il blinking del led verde durante LANDING e TAKEOFF.
	\item \textbf{HangarTask}: Gestisce la macchina a stati dell'hangar divisa in DRONE INSIDE, DRONE TAKEOFF, DRONE OUTSIDE, DRONE LANDING.
	\item \textbf{HangarDoorTask}: Gestisce l'apertura e chiusura della porta dell'hangar in base allo stato dell'hangar. Quando l'hangar è in DRONE TAKEOFF o DRONE LANDING apre la porta e aggiorna le altre task quando la porta è completamente aperta (poiché non è un'azione immediata). Quando l'hangar è in DRONE INSIDE o DRONE OUTSIDE e la porta è aperta, inizia a chiuderla quando il drone risulta dentro.
	\item \textbf{LCDTask}: Mostra lo stato corrente dell'hangar all'operatore.
	\item \textbf{SerialCommTask}: Gestisce lo scambio di comandi tra l'Arduino e l'applicazione Java.
\end{itemize}
